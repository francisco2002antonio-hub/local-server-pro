# Local Server Pro

Servidor local profesional para Android.

## Características previstas

- Servidor HTTP
- Servidor FTP
- Servidor WebDAV
- Motor PHP
- Base de datos SQLite
- Administrador de archivos
- Alojamiento web local
- Usuarios y permisos
- Acceso mediante código QR
- Funcionamiento en segundo plano
- Sin Termux
- Sin root

## Desarrollo

Lenguaje: Kotlin
Paquete: mx.localserver.pro
Versión inicial: 1.0.0
Compilación: GitHub Actions
